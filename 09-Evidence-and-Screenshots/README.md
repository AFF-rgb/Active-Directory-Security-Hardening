# 09 — Project Diagrams

This chapter contains illustrative diagrams that explain the lab architecture and security-control relationships. These visuals are designed for portfolio presentation; they are not screenshots and do not independently prove that a configuration or validation was performed.

## Available diagrams

## Lab components represented

- Domain: `stech.net`
- Domain controller: `DC01-LAB` — Windows Server 2022
- Client: Windows 10 Pro (Client A)
- Department shares: `IT_Share` and `HR_Share`
- Mapped drive: `Z:\\` containing the hidden `CompanyData$` share

Diagrams summarize the documented lab design. Implementation details and validation results remain in their respective project chapters.
